## Cómo levantar el proyecto desde cero
1. Copiar la plantilla de variables de entorno:
   `cp .env.example .env`
2. Editar el archivo `.env` con contraseñas seguras.
3. Levantar los contenedores en segundo plano:
   `docker compose up -d`
4. Acceder a la aplicación en `http://localhost:3000`.
